Installation

Follow these steps to get Project 1 running locally.

Requirements

  • Modern browser
  • Text editor
  • Optional local web server for faster development

Steps

  1. Clone or download the project folder.
  2. Open the folder in your preferred editor.
  3. Open index.html in a browser or serve the folder using a local server.
