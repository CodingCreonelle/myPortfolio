Architecture

This page covers how the project is organized and how the main parts are connected.

Project layout

  • index.html — entry point for the project.
  • assets/css/ — primary styling files for pages, navigation, and components.
  • assets/js/ — interactive scripts and behavior logic.

Design approach

Keep content separate from styling and behavior so the project remains easy to maintain. Reuse shared assets, keep sections modular, and rely on simple HTML structure for flexibility.
