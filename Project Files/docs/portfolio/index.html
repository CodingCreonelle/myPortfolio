Portfolio Documentation

This documentation homepage explains the portfolio structure, content organization, and styling conventions used throughout the site.

What’s included

  • Homepage: A hero section, featured projects, skills preview, and contact call-to-action.
  • Projects page: A complete project listing with summaries and links.
  • About page: Biography, skills, and career goals.
  • Contact page: Contact details and a message form template.

Folder structure

The portfolio is organized by page type, shared assets, data sources, documentation, and project demos. This makes it easy to add new pages and maintain content over time.

Getting started

Open the root index.html file in a browser or serve the folder with a local web server to preview the portfolio.
